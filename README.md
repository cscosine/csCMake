# csCMake

a set of utils and wrapper over CMake to create and manage projects

## How to use

- checkout in a folder, e.g., `projects` where then other projects will be checkout. Your folder structure will look like

```
projects
  csCMake
    csCMake.cmake
    README.md
    ...
  proj_A
    proj_A
      source.cpp
      ...
```
